# mod-3-casestudy-1-3-1

Document QA Assistant - Android RAG Application with FastAPI Backend.

## Features
- **Upload Document**: Upload PDF, DOCX, TXT, or MD files to the backend vector store (FAISS).
- **Document QA**: Ask questions based on uploaded documents with AI responses and cited sources.
- **FastAPI RAG Backend**: FastAPI server with LangChain text splitters, SentenceTransformers, and FAISS indexing.
